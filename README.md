# WiseWear

Публичная витрина приложения WiseWear — приватного цифрового гардероба с AI-стилистом.

Сайт собран как статика (HTML + CSS + JS без сборщика) и публикуется через GitHub Pages.

## Структура

```
index.html              # разметка страницы
assets/css/style.css    # стили, дизайн-токены из приложения
assets/js/main.js       # меню, тень шапки, появление блоков ( progressive enhancement )
assets/img/*.png        # реальные скриншоты приложения
.nojekyll               # отключить Jekyll на Pages
```

## Локальный просмотр

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Сборка не нужна — это чистая статика.

## Правки

- Токены палитры лежат в `:root` файла `assets/css/style.css` и совпадают с
  дизайн-токенами приложения (`src/index.css`).
- Скриншоты переснимаются из dev-сервера приложения на порту 5173.
- Внешних зависимостей нет: ни шрифтов из CDN, ни аналитики, ни трекеров.
